# Provenance and attribution

## What this repository is

**Clow Waves Web** is an unofficial, standalone web adaptation based substantially on the existing **[Maurdekye/orgtree](https://github.com/Maurdekye/orgtree)** implementation called **Claude Waves**. The upstream author did the core research and implementation of the ASCII wind field and ripple renderer. This repository is *not* a from-scratch replacement for that contribution.

| This repository | Upstream origin | Relationship |
| --- | --- | --- |
| `src/field.ts` | [`asciifield.ts`](https://github.com/Maurdekye/orgtree/blob/main/apps/desktop/renderer/src/canvas/asciifield.ts) | Adaptation of field maths, glyph pools, touch model, noise functions |
| `src/gl.ts` | [`asciigl.ts`](https://github.com/Maurdekye/orgtree/blob/main/apps/desktop/renderer/src/canvas/asciigl.ts) | Adaptation of WebGL2 pipeline, glyph atlas, shader mathematics |
| `src/controller.js` | New web integration around the adapted modules | Standalone lifecycle, interactions, configuration, renderer selection |
| `src/fallback.js` | Adapts the field/atlas computation | Canvas 2D approximate fallback |
| `dist/` and standalone HTML | Built from above + demo | Generated distribution and demo UI |
| `examples/`, `scripts/` | Project-specific integration | Installation and tests |

## Relationship to Anthropic / Claude

The Orgtree author's [technical documentation](https://github.com/Maurdekye/orgtree/blob/main/docs/rust-engine/canvas-background-themes.md) describes a study of a user-provided Claude renderer excerpt, which was reduced to mathematical notes, followed by an independent reimplementation. **This is a statement of the upstream project's described process, not an independently verified legal clearance from Anthropic.** This adaptation used publicly available Orgtree source files, not Anthropic proprietary application source code. We have not obtained Anthropic's permission or endorsement.

Claude and Anthropic are trademarks of their respective owners. The name *Claude Waves* appears solely to identify the upstream feature accurately. This project is unofficial and independent, not affiliated with or endorsed by Anthropic.

The example still images under `preview/` were generated by the resulting renderer. Neither the user-provided reference videos nor the original application graphics and installers are redistributed.

## Independent contributions

The web port introduces a reusable browser component API; extra presets; script and ESM builds; React/Next.js and vanilla HTML examples; mouse/touch filtering; fallback Canvas 2D; configurable visual parameters; browser lifecycle and accessibility handling; automated lifecycle tests; and project documentation.

## Scope and limitations

The appearance is calibrated from recordings and known mathematics. Fonts, rendering engines, pixel density, random seeds, compositor details, and session-specific timings vary. Therefore this project **does not claim pixel-perfect identity or official compatibility with Anthropic's products**. Its provenance and license statements do not independently resolve third-party rights claims. Please evaluate downstream use accordingly.
