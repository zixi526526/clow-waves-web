# Clow Waves Web

An unofficial, standalone WebGL2 ASCII-wave and interactive-ripple background for websites.

> **Attribution:** The core field mathematics, glyph selection, circular/heart ripple effects, and WebGL2 rendering are substantially adapted from **[Maurdekye/orgtree](https://github.com/Maurdekye/orgtree)**, where the feature is called *Claude Waves*. All credit for the essential original implementation belongs to the upstream author. Copyright (c) 2026 Maurdekye, MIT License.

## Status

The standalone port and demonstration are prepared, but **the full source and distribution files have not yet been uploaded to this GitHub repository**. Do not treat this repository as an installable package until those files are present.

## Planned contents

- Reusable JavaScript web background (script and ESM)
- WebGL2 renderer and Canvas 2D fallback
- Circular and heart-shaped ripple interactions
- Light, warm, and dark presets
- Vanilla HTML and React integration examples
- Offline single-HTML demonstration
