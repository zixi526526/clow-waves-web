# Build & hosting / 构建与托管

**[▶ Demo](https://fluxarium.pages.dev/effects/clow-waves/)** — The interactive showcase is managed by Fluxarium.

This document covers building and hosting the standalone renderer artifacts. The existing Pages project is kept for compatibility, not as an additional promoted demo.

## Build and validate / 构建与校验

The distribution assets in `dist/` are generated by Node.js 22.18+:

```bash
npm run build
npm run check
```

The runtime component is static and requires no backend, API key or credentials.

## Cloudflare Pages (maintenance only)

Current configuration: the `zixi526526/clow-waves-web` repository connects to the `clow-waves-web` Pages project, with `main` as production branch and `dist` as the output directory.

If the GitHub integration is enabled, existing built assets in `dist/` are automatically deployed when `main` changes. No build command is required because the generated assets are committed to this repository.

For a manual upload:

```bash
npx wrangler pages deploy dist --project-name=clow-waves-web --branch=main
```

For a local static server:

```bash
npx wrangler pages dev dist
```
